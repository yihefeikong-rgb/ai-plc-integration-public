## 项目风险

### R-001：TIA Portal Openness 授权依赖

- **风险**：TIA Portal Openness 需要西门子高级授权，开发/生产环境受限
- **严重度**：高
- **可能性**：中
- **影响**：无法在无授权机器上运行 TIA MCP；CI/CD 和团队协作受限
- **缓解措施**：
  - 明确记录 TIA 授权要求
  - 提供软授权/本地 PLCSIM 替代方案
  - 避免将 TIA Openness 调用放入必须路径
- **负责人**：team-lead
- **状态**：已识别

### R-002：PLC 实机操作安全

- **风险**：AI 直接控制 PLC 可能造成设备损坏或安全事故
- **严重度**：高
- **可能性**：低（已有多层防护）
- **影响**：设备停机、人员伤害、法律责任
- **缓解措施**：
  - 禁止 AI 操作急停回路
  - 所有控制指令经互锁检查 + 影子仿真
  - 生产写入需双人确认
  - 审计日志 HMAC 链式哈希
- **负责人**：reviewer + safety 模块
- **状态**：已缓解

### R-003：Project Brain 建设失败

- **风险**：`.plans/` 文件流于形式，知识仍依赖聊天记录
- **严重度**：高
- **可能性**：中
- **影响**：上下文继续爆炸，反复推翻设计
- **缓解措施**：
  - 建立 Documenter 角色
  - 每次会话结束强制更新 `handoff.md`
  - team-lead 每次验收时检查文档一致性
- **负责人**：team-lead + documenter
- **状态**：缓解中

## 依赖风险

### R-004：DeepSeek API 稳定性

- **风险**：模型不可用或响应延迟
- **严重度**：中
- **可能性**：中
- **影响**：对话功能不可用
- **缓解措施**：
  - 已支持 5 家模型供应商切换
  - 本地缓存 + 离线提示词模板
- **负责人**：developer
- **状态**：已缓解

### R-005：PLCSIM Advanced 版本兼容性

- **风险**：不同版本 PLCSIM API 行为不一致
- **严重度**：中
- **可能性**：中
- **影响**：下载/仿真失败
- **缓解措施**：
  - 当前锁定 V8.0
  - 启动脚本自动检测 golden backup 路径
  - 文档记录版本约束
- **负责人**：developer
- **状态**：已缓解

### R-006：PythonNET / .NET Framework 依赖

- **风险**：TiaWorker 依赖 .NET Framework 4.8，新环境配置复杂
- **严重度**：中
- **可能性**：中
- **影响**：新成员/新机器难以上手
- **缓解措施**：
  - 提供启动脚本
  - 文档记录安装步骤
  - 考虑未来迁移到 .NET 8+
- **负责人**：developer
- **状态**：已识别

## 模型风险

### R-008：LLM 输出不可预测

- **风险**：LLM 生成的 PLC 代码、梯形图、诊断结果可能错误
- **严重度**：高
- **可能性**：高
- **影响**：直接写入 PLC 导致设备异常
- **缓解措施**：
  - 所有生成结果经影子仿真验证
  - 关键写入需人工确认
  - 安全层互锁规则拦截危险操作
- **负责人**：safety 模块 + reviewer
- **状态**：已缓解

### R-009：多模型切换导致行为不一致

- **风险**：不同模型对同一提示词输出差异大
- **严重度**：中
- **可能性**：中
- **影响**：测试结果不稳定，用户体验不一致
- **缓解措施**：
  - 统一系统 Prompt
  - 输出格式强制 JSON schema 校验
  - fallback 时通知用户
- **负责人**：developer
- **状态**：已识别
