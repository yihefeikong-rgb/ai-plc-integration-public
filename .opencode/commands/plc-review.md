# project:plc-review — 工业 PLC 代码安全审查

审查当前项目中的 PLC 相关代码（MCP 服务器、CartGen 模板、安全模块等）。

## 审查范围

### ⛔ 安全红线检查
- [ ] 是否有代码直接操作急停回路（ESTOP / EMERGENCY / SAFETY 标签）
- [ ] 是否尝试修改安全 PLC（F-CPU）参数
- [ ] 是否绕过了影子仿真验证
- [ ] API Key 是否从 `.env` 读取（不是硬编码）

### 🔒 写入安全检查
- [ ] 写入操作前是否调用了安全验证
- [ ] 是否检查了禁止写入的标签模式（急停/安全相关）
- [ ] 熔断机制（consecutive_errors 阈值）是否生效

### 📝 审计合规
- [ ] 每次写入操作后是否记录审计日志（action, target, value, operator, timestamp）
- [ ] 审计日志是否可篡改（应使用只追加模式）

### 📐 代码生成规范（SCL/LAD）
- [ ] 是否包含急停互锁
- [ ] 正转/反转是否互锁
- [ ] 过载保护
- [ ] 变量命名是否符合匈牙利命名法（bEmergencyStop, rMotorSpeed）
- [ ] 是否包含输入验证、输出限幅

## 输出格式

### 🔴 严重
（违反安全红线 — 必须修复）

### 🟡 警告
（不符合规范但非紧急 — 建议修复）

### 🔵 建议
（可优化项）

每个问题附带文件路径 + 行号 + 修复建议。
