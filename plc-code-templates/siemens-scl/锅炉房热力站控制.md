# 锅炉房/热力站控制 — BoilerHeatingStation

## 功能概述

锅炉房/热力站群控系统，含多锅炉加减炉（负荷分配）、气候补偿曲线、一次/二次泵联动、混水阀PID调节、回水温度保护、烟气监测连锁。

## 适用场景

- 集中供暖锅炉房（燃气/燃油/电锅炉）
- 换热站/热力站（板换+混水）
- 区域供热二次网调节
- 北方城市建筑供暖系统

## 控制策略

### 气候补偿曲线
- 根据室外温度自动计算目标供水温度
- 室外越冷 → 供水越热（线性补偿）
- 设计工况：室外-15degC → 供水80degC
- 过渡季：室外15degC → 供水35degC

### 加减炉逻辑
| 条件 | 动作 | 延时 |
|------|------|------|
| 负荷 > 80% 且单炉 | 加炉 | 10min |
| 负荷 < 30% 且双炉 | 减炉 | 15min |
| 负荷 > 5% 且无炉运行 | 启动1台 | 即时 |

### 均衡轮换
- 加炉选累计运行时间最短的锅炉
- 减炉停累计运行时间最长的锅炉
- 泵每720小时主备切换

### 混水阀PID
- 控制对象：二次供水温度
- 调节手段：混水阀开度（调节一次高温水与二次回水混合比例）

## 安全规则

1. 急停无条件停所有设备
2. 非采暖季自动停机
3. 烟气温度>180degC持续10s报警（防止排烟超标/异常燃烧）
4. 回水温度<30degC持续60s报警+限制混水阀（防热冲击）
5. 系统压力越限（<1bar或>6bar）报警
6. 故障锅炉自动退出加减炉选择
7. 主泵故障自动切备泵
