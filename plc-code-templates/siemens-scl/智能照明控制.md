# 智能照明控制 — LightingControl

## 功能概述

智能照明系统，含时间表控制、人体感应联动、恒照度调光、场景模式切换（6种）、渐变输出、应急照明状态监控。

## 适用场景

- 商业办公楼层照明控制
- 会议室/多功能厅场景照明
- 地下车库/走廊人感照明
- 酒店客房/公共区域照明

## 接口定义

### 输入
| 信号 | 类型 | 说明 |
|------|------|------|
| bEnable | Bool | 系统使能 |
| bEmergencyStop | Bool | 急停（常闭） |
| rLuxLevel | Real | 照度传感器 (Lux) |
| bMotionDetect1~3 | Bool | 人体感应器 |
| bDoorContact | Bool | 门磁开关 |
| iHour / iMinute | Int | 当前时间 |
| iDayOfWeek | Int | 星期 (1=周一) |
| bHoliday | Bool | 节假日 |
| rLuxSetpoint | Real | 照度设定 (Lux) |
| iOnHour / iOffHour | Int | 时间表范围 |
| iDelayOff | Int | 无人延迟关灯 (秒) |
| iSceneCmd | Int | 场景命令 |

### 输出
| 信号 | 类型 | 说明 |
|------|------|------|
| rZone1~3Dim | Real | 各区域调光 (0-100%) |
| bEmergencyLight | Bool | 应急照明激活 |
| bOccupied | Bool | 区域有人 |
| iActiveScene | Int | 当前场景 |

## 场景预设

| 场景 | 命令值 | 调光 | 适用 |
|:----:|:------:|:----:|------|
| 全亮 | 1 | 100% | 清洁/应急 |
| 办公 | 2 | 70% | 日常办公 |
| 会议 | 3 | 80% | 会议讨论 |
| 投影 | 4 | 20% | 演示/影音 |
| 清洁 | 5 | 100% | 保洁时段 |
| 全关 | 6 | 0% | 下班/离场 |

## 控制策略

### 自动模式优先级
1. 场景命令 > 自动模式
2. 有人 + 在时间表 → 恒照度PID调光
3. 在时间表 + 无人 → 低亮待机(20%)
4. 非时间表 + 无人 → 全关

### 恒照度控制
- 照度传感器采集工作面照度
- PID调节人工照明补偿自然光变化
- 自然光充足时自动降低灯具亮度节能

### 渐变输出
- 所有调光变化经5%/cycle渐变平滑
- 避免突变闪烁，提升舒适度

## 安全规则

1. 急停触发应急照明（电池供电指示灯）
2. 最低亮度限制10%（有人时不全黑）
3. 人感延时可配（默认5分钟无人后关灯）
4. 节假日按非工作日时间表处理
