# 恒压供水群控 — ConstPressureWater

## 功能概述

变频恒压供水群控系统，含PID恒压控制、多泵加减泵（阶梯启停）、运行时间均衡轮换、小流量休眠/自动唤醒、缺水保护、超压保护。

## 适用场景

- 高层住宅/商业楼宇二次供水
- 工业厂房生产供水
- 市政管网加压泵站
- 恒压变频一拖多供水系统

## 接口定义

### 输入
| 信号 | 类型 | 说明 |
|------|------|------|
| bEnable | Bool | 系统使能 |
| bReset | Bool | 故障复位 |
| bEmergencyStop | Bool | 急停（常闭） |
| rPressureActual | Real | 管网实际压力 (bar) |
| rPressureSetpoint | Real | 压力设定值 (bar) |
| bPump1~3Run | Bool | 水泵运行反馈 |
| bPump1~3Fault | Bool | 水泵故障 |
| rTankLevel | Real | 水箱液位 (%) |
| rFlowRate | Real | 管网流量 (m3/h) |
| bLowLevelSwitch | Bool | 低液位开关 |
| rVFDFreqActual | Real | VFD实际频率 |
| rSleepFlow / rWakeFlow | Real | 休眠/唤醒流量阈值 |

### 输出
| 信号 | 类型 | 说明 |
|------|------|------|
| bPump1~3Cmd | Bool | 泵启停命令 |
| rVFDFreqCmd | Real | VFD频率设定 (0-50Hz) |
| iPumpVFD | Int | 当前变频泵编号 |
| iRunningPumps | Int | 运行泵数 |
| bSleepMode | Bool | 休眠模式 |
| bPressureAlarm / bLevelAlarm / bPumpAlarm | Bool | 报警 |

## 控制策略

### PID恒压
- 管网压力作为反馈，VFD频率为输出
- PID参数：Kp=4.0, Ki=0.2, Kd=0.5（可调）

### 加减泵
| 条件 | 动作 | 延时 |
|------|------|------|
| 频率≥48Hz 且 压力偏低 | 加泵 | 30s |
| 频率≤25Hz 且 多泵运行 | 减泵 | 60s |

### 轮换策略
- 加泵选运行时间最短的泵
- 减泵停运行时间最长的泵
- 故障泵自动退出选择池

### 休眠/唤醒
- 流量<0.5m3/h 且 压力达标，持续120s → 休眠（全泵停止保压）
- 流量>1.0m3/h 或 压力下降0.3bar → 自动唤醒恢复供水

## 安全规则

1. 急停无条件停所有泵
2. 水箱液位<10% 或 低液位开关 → 停泵保护
3. 超压强制降频保护
4. 故障泵自动退出，不参与轮换
5. 缺水保护液位恢复>30%后方可复位
