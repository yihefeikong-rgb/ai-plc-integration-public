# 停车场管理系统 (ParkingManagement)

## 功能概述

全自动停车场出入口管理，支持入口读卡抬杆、车位计数、满位显示、防砸保护等功能。

## 适用场景

- 商业停车场、写字楼停车场、小区停车场
- 单入口单出口配置
- 读卡/扫码入场

## 接口定义

### 输入
| 信号 | 类型 | 说明 |
|------|------|------|
| bEnable | Bool | 系统使能 |
| bReset | Bool | 故障复位/计数清零 |
| bEmergencyStop | Bool | 急停（常闭） |
| bManualMode | Bool | 手动控制模式 |
| bEntranceLoop / bExitLoop | Bool | 入口/出口地感线圈 |
| bEntranceGateUpLimit / DnLimit | Bool | 入口道闸上下限位 |
| bExitGateUpLimit / DnLimit | Bool | 出口道闸上下限位 |
| bEntranceSafetyLight / bExitSafetyLight | Bool | 入口/出口红外安全光幕 |
| bCardReaderEntry / bCardReaderExit | Bool | 入口/出口读卡有效脉冲 |
| iTotalSpaces | Int | 总车位数 |

### 输出
| 信号 | 类型 | 说明 |
|------|------|------|
| bEntranceGateUp / Dn | Bool | 入口道闸升降 |
| bExitGateUp / Dn | Bool | 出口道闸升降 |
| bFullSign | Bool | 满位指示灯 |
| iAvailableSpaces | Int | 剩余车位实时值 |
| bEntryGreenLight / bEntryRedLight | Bool | 入口可入/禁行指示 |
| bAlarm | Bool | 系统故障 |

## 状态机

### 入口状态
| 状态 | 说明 |
|------|------|
| IDLE | 等待读卡 |
| GATE_UP | 读卡成功，抬杆 |
| WAIT_VEHICLE | 等待车辆压入地感 |
| VEHICLE_IN | 车辆通过检测 |
| GATE_DN | 落杆完成 |

### 出口状态
与入口对称，含读卡→抬杆→车辆离开→落杆

## 控制策略

1. **车位计数**：地感线圈上升沿→下降沿计为一车，入口+1出口-1
2. **满位控制**：iOccupied >= iTotalSpaces 时禁止入场
3. **防砸保护**：安全光幕触发时立即抬杆停止落杆
4. **自动复归**：读卡后10秒无人/车通过，自动落杆
5. **余位显示**：实时计算并输出剩余车位

## 安全规则

1. 急停无条件中断所有输出
2. 道闸上下限位保护
3. 红外+地感双重防砸检测
4. 入口满位时拒绝读卡入场
5. 手动模式下状态机可被旁路
