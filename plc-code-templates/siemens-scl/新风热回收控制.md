# 新风热回收控制 — HeatRecoveryVent

## 功能概述

新风热回收系统控制，含转轮/板换热回收效率调节、焓值经济器旁通判断、预热盘管PID、CO2需求控制、防冻保护、过滤器监控。

## 适用场景

- 全热交换新风机组
- 显热交换新风机组
- 转轮式热回收系统
- 板式热交换器新风机组
- 与AHU配合使用的独立新风系统

## 控制策略

### 模式切换
| 模式 | 条件 | 说明 |
|:----:|------|------|
| RECOVERY | 室外温差大或焓值不适宜 | 转轮/板换全力回收 |
| BYPASS | 室外15~22degC且焓值<室内 | 旁通直接引入新风（免费冷却） |
| FREEZE | 防冻温度<3degC | 停送风，全开预热阀 |
| OFF | 无人或未使能 | 全关 |

### 焓值经济器
- 比较室内外焓值（简化估算）
- 室外焓值更低时切旁通模式，利用自然冷源
- 避免无效回收（过渡季室外已是舒适温度）

### 热回收效率控制
- 转轮转速随室内外温差线性增加（5%/degC）
- 最低30%最高100%
- 实际效率实时计算 = (送风温-室外温)/(室内温-室外温)

### 预热盘管
- 冬季送风温度过低时辅助加热
- PID调节热水阀开度
- 与热回收串联提升整体效率

## 安全规则

1. 急停无条件停风机、关风阀
2. 防冻传感器<3degC持续5s → 停送风+全开预热
3. 防冻解除需温度恢复>8degC
4. 过滤器压差>200Pa持续60s → 报警
5. 风机过载立即停机
6. 非占用时段自动停机节能
