# 电梯控制系统 (ElevatorControl)

## 功能概述

多楼层电梯集选控制，支持轿厢内选层和厅外召唤、顺向截梯、消防归底等功能。

## 适用场景

- 住宅楼、办公楼、商场等多楼层电梯
- 支持 2-6 层（可扩展至更多楼层）
- 单梯集选控制

## 接口定义

### 输入
| 信号 | 类型 | 说明 |
|------|------|------|
| bEnable | Bool | 系统使能 |
| bReset | Bool | 故障复位 |
| bEmergencyStop | Bool | 急停（常闭） |
| bDoorClosed / bDoorOpened | Bool | 门状态反馈 |
| bDoorObstructed | Bool | 门障碍物检测 |
| bOverload | Bool | 超载检测 |
| bFireReturn | Bool | 消防归底信号 |
| bCarCall1~6 | Bool | 轿厢内呼（1-6层） |
| bHallUp2~5 | Bool | 厅外上召唤（2-5层） |
| bHallDn2~6 | Bool | 厅外下召唤（2-6层） |
| bFloorSensor1~6 | Bool | 楼层到位传感器 |
| tiDoorOpenDelay | Time | 开门保持时间 |
| tiDoorCloseDelay | Time | 关门时间 |

### 输出
| 信号 | 类型 | 说明 |
|------|------|------|
| bMotorUp / bMotorDown | Bool | 上下行接触器 |
| bDoorOpenCmd / bDoorCloseCmd | Bool | 开关门指令 |
| bFloorDisplay | Byte | 楼层显示编码 |
| bDirectionUp / bDirectionDn | Bool | 方向指示 |
| bAlarm | Bool | 故障报警 |
| bFireMode | Bool | 消防模式指示 |
| iCurrentFloor | Int | 当前楼层 |

## 状态机

| 状态码 | 状态名 | 说明 |
|:------:|--------|------|
| 0 | IDLE | 空闲，等待请求 |
| 1 | MOVING | 运行中，含顺向截梯 |
| 2 | DOOR_OPEN | 开门保持 |
| 3 | DOOR_CLOSING | 关门（含防夹） |
| 4 | FAULT | 故障停车 |
| 5 | FIRE | 消防归底模式 |

## 控制策略

1. **集选控制**：轿厢内呼和厅外召唤统一管理，按上行/下行方向分别排队
2. **顺向截梯**：运行方向上的请求顺路停靠，提高效率
3. **方向决定**：当前方向完成后，反方向最高/最低请求变为新方向
4. **门控时序**：开门→保持（tiDoorOpenDelay）→关门→等待门关到位
5. **安全互锁**：门未关到位不能运行，超载/障碍物不关门

## 安全规则

1. 急停（bEmergencyStop 常闭）无条件中断所有输出
2. 门锁未闭合 → 禁止运行
3. 超载 → 开门并保持，不能运行
4. 消防归底 → 无条件返回1层开门
5. 运行超时（tiMoveTimeout）→ 故障报警
