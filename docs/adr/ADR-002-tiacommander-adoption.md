# TiaCommander 正式采用决策框架

> 日期：2026-07-22
> 状态：评估完成，待决策

## 方案 A：正式作为可选 Provider

**前置条件**（必须全部满足）：

- [ ] 获得作者书面许可，确认集成条款
- [ ] V21 关键测试通过（当前使用 V18 API，需验证 V21 兼容性）
- [ ] 网络修改稳定可靠
- [ ] 返回结果可结构化解析
- [ ] 不会绕过 Gateway 安全链
- [ ] 不包含二进制和许可证信息在仓库中
- [ ] 高风险动作默认禁用

**建议路径**：
1. 将 TiaCommander 二进制移至仓库外（如 `C:\TiaCommander\`）
2. 在 `plc-gateway/providers/tiacommander.py` 中实现 Provider 适配器
3. 通过环境变量 `TIA_COMMANDER_ENABLED=1` 启用
4. 默认 `enabled: false`，不随公开仓库分发

## 方案 B：仅作为个人工程工具

**适用条件**：
- 技术能力很好
- 但许可证不允许项目集成

**规则**：
- 不出现在公开产品运行链路
- 不由项目后端自动调用
- 只在隔离项目中由人工使用
- 项目继续独立开发 TiaWorker

## 方案 C：停止用于本项目

**适用条件**：
- 作者明确认为项目属于竞争产品
- 或拒绝外部集成授权

**行动**：
- 保留已有的独立测试记录
- 不再通过它开发同类能力
- 完全依赖 TiaWorker

## 当前建议

**建议采用方案 B**：在获得作者书面许可前，TiaCommander 仅作为本地开发辅助工具，不进入公开仓库的正式运行链路。TiaWorker 继续作为项目正式后端。
