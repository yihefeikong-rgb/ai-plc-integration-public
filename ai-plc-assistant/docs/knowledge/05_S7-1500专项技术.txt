西门子 S7-1500 专项技术手册

========================================
第一部分：S7-1500 与 S7-1200 对比
========================================

性能参数对比：
  - 数据工作内存：S7-1200 50-150KB / S7-1500 250KB-150MB
  - 代码工作内存：S7-1200 50-150KB / S7-1500 250KB-18MB
  - 装载内存：S7-1200 内置+可选存储卡 / S7-1500 必须使用存储卡（最大32GB）
  - I/O 地址空间：S7-1200 1024字节 / S7-1500 32KB
  - 位操作速度：S7-1200 约0.08微秒 / S7-1500 约0.001-0.05微秒
  - 扩展模块数：S7-1200 最多8个 / S7-1500 最多32个/站
  - 运动控制轴数：S7-1200 4-6轴（PTO/PWM）/ S7-1500 最多128轴
  - 最大 I/O 点数：S7-1200 284数字/51模拟 / S7-1500 8192数字/1024模拟

编程语言差异：
  - S7-1200 支持：LAD, FBD, SCL
  - S7-1500 额外支持：STL（语句表）, S7-Graph（顺序功能图）
  - S7-1500 支持 ProDiag（程序诊断）和断点调试
  - S7-1500 支持下载时不重新初始化（Download without reinitialization）

硬件差异：
  - S7-1500 有前面板显示屏（可显示诊断/IP/状态）
  - S7-1500 有物理 RUN/STOP 选择开关
  - S7-1500 支持冗余（R/H 系列热备份）
  - S7-1500 内置 OPC UA 服务器和 Web 服务器
  - S7-1500 功耗约 40W，S7-1200 约 20W

兼容性注意事项：
  - S7-1200 代码几乎可直接复制到 S7-1500
  - 反向迁移可能因 S7-1500 独有指令而失败
  - TIA Portal Basic（S7-1200）约 $700，Professional（S7-1500）约 $7000

========================================
第二部分：优化数据块（Optimized DB）
========================================

核心概念：
  优化数据块是 S7-1500 的默认设置，数据元素仅通过符号名寻址，
  没有固定偏移地址。系统自动优化数据的内存排列，消除间隙。

优势：
  - 更快的访问速度：CPU 用一条指令直接读写数据
  - 更大的块容量：标准块最大 64KB，优化块最大 16MB
  - 灵活的保持性设置：每个标签可单独设置 Retain
  - 无地址冲突：增删变量不影响其他变量地址
  - 支持下载不重初始化：可在 RUN 模式下修改接口

必须使用标准数据块的场景：
  - PUT/GET 单向通信（发送/接收区域必须用标准 DB）
  - 连接 WinCC V7.2 HMI（所访问的 DB 必须是标准块）
  - 使用 SIMATIC Net V8.2 OPC 连接时
  - 需要绝对寻址的外部通信

外部系统访问优化 DB 的方法：
  - OPC UA（最佳方案，S7-1500 FW>=V2.5 支持）
  - BSEND/BRECV（原生 S7 协议）
  - TSEND_C/TRCV_C（TCP 通信）
  - 创建非优化的"交换 DB"用于 GET/PUT

========================================
第三部分：Web 服务器与诊断
========================================

Web 服务器配置步骤：
  1. CPU 属性 > 常规 > Web 服务器
  2. 勾选"在此模块上激活 Web 服务器"
  3. 创建用户账户，分配密码和权限
  4. 为需要访问的接口启用 Web 服务器
  5. 编译并下载到 CPU
  6. 浏览器访问 https://CPU_IP

Web 服务器提供的功能：
  - CPU 状态（LED 映射和当前运行模式）
  - 诊断缓冲区读取
  - 模块状态查询
  - 当前报警
  - 拓扑/PROFINET 设备状态
  - 用户自定义网页
  - Motion Control 状态监控
  - 配方管理
  - Web API（JSON-RPC 2.0）

诊断缓冲区：
  - CPU 1516 可保存最多 3200 条诊断消息
  - CPU 1511/1513 可保存 1000 条
  - 诊断事件包括：模块错误、CPU 系统错误、运行模式转换、用户程序错误、模块插拔、安全事件
  - 内容存储在保持性内存中，CPU 复位后不丢失
  - 可通过 CSV 导出

Web API 端点：https://PLC_IP/api/jsonrpc
  支持的 API 方法：
  - Plc.ReadOperatingMode / Plc.RequestChangeOperatingMode
  - Plc.ReadSystemTime / Plc.ReadTimeSettings
  - Api.BrowseTickets / Api.CloseTicket
  - 文件上传/下载（通过 Ticket 机制）

安全要求：
  - 推荐使用 HTTPS（端口 443）并配置 CA 签名证书
  - Web 服务器默认在 CPU 出厂时关闭

========================================
第四部分：LED 指示灯含义
========================================

RUN/STOP LED：
  - 绿色常亮：RUN 模式
  - 黄色常亮：STOP 模式
  - 黄/绿交替闪烁：启动中（STOP→RUN 过渡）
  - 黄色闪烁：STOP 中执行内部操作/固件更新/断点调试

ERROR LED：
  - 红色常亮：发生错误
  - 红色闪烁：存在诊断事件/存储卡程序错误/固件更新失败
  - 熄灭：无错误

MAINT 维护 LED：
  - 黄色常亮：需要维护（PROFINET 环中断/硬件需检查）
  - 黄色闪烁：固件更新完成/存在 Force 作业/OPC UA 等待信任列表

LINK RX/TX LED（每端口）：
  - 绿色常亮：存在以太网连接
  - 绿色闪烁：数据传输中
  - 熄灭：无以太网连接

全部 LED 同时闪烁：启动时自检

S7-1500 与 S7-1200 LED 差异：
  - S7-1200 没有 MAINT LED、没有前面板显示屏
  - S7-1500 可通过指令"LED"在用户程序中读取 LED 状态

========================================
第五部分：技术对象（Technology Objects）
========================================

运动控制技术对象：
  速度轴 TO_SpeedAxis — 速度设定，计算输出到驱动
  定位轴 TO_PositioningAxis — 闭环位置控制
  同步轴 TO_SynchronousAxis — 跟随主轴运动（仅 S7-1500T）
  外部编码器 TO_ExternalEncoder — 检测位置
  测量输入 TO_MeasuringInput — 信号变化时精确检测位置
  输出凸轮 TO_OutputCam — 根据轴位置生成开关信号
  凸轮轨道 TO_CamTrack — 开关信号序列
  凸轮 TO_Cam — 传递函数（仅 S7-1500T）
  运动学 TO_Kinematics — 多轴互连运动学（仅 S7-1500T）

S7-1500 vs S7-1500T 差异：
  标准 S7-1500：速度轴、定位轴、外部编码器、测量输入、输出凸轮
  S7-1500T 额外：同步轴、凸轮、运动学、解释器
  最大 Motion Control 资源：160 个

高速计数器与技术模块：
  C 型 CPU（1511C/1512C）集成 HSC/PTO/PWM
  TM Count 2x24V — 2 通道计数器模块
  TM Timer DIDQ — 时间控制数字 I/O
  TM PTO 4 — 4 通道脉冲列输出（用于步进电机）

========================================
第六部分：内存管理
========================================

三层内存架构：
  装载内存（Load Memory）— 非易失性，位于存储卡
    存储代码块、数据块、技术对象、硬件配置
    最大 32GB，CPU 运行必须插卡

  工作内存（Work Memory）— 易失性，CPU 集成
    运行时相关代码和数据
    分为代码工作内存和数据工作内存
    不可扩展

  保持性内存（Retentive Memory）— 非易失性，CPU 集成
    掉电保持的数据
    优化块中每个标签可单独设置保持性
    仅"恢复出厂设置"会清除所有保持性内存

内存监控方式：
  TIA Portal 在线：在线与诊断 > 诊断 > 内存
  CPU 前面板显示屏：内存菜单
  Web 服务器：诊断 > 内存

下载不重初始化（Download without reinitialization）：
  优化块默认含内存预留区
  可在 RUN 模式下修改接口而不影响已有标签实际值
  需在数据块属性中激活

========================================
第七部分：固件更新
========================================

方式一：通过 SIMATIC 存储卡
  1. 存储卡插入 PC 读卡器
  2. TIA Portal 项目树中选择存储卡
  3. 项目 > 读卡器/USB 存储 > 创建固件更新存储卡
  4. 选择固件更新文件
  5. 将存储卡插入 CPU，固件更新自动开始
  6. 完成后 RUN LED 黄色常亮，MAINT 黄色闪烁
  7. 取出存储卡或转换为程序卡

方式二：通过 STEP 7 在线更新
  1. 在线菜单 > 可访问的设备
  2. 搜索并选择目标设备
  3. 设备在线与诊断 > 功能 > 固件更新

注意事项：
  - 存储卡容量必须足够
  - 更新 CPU 同时可更新显示屏和集中模块
  - 安全建议：保持固件为最新版本
  - 固件目录结构：FWUPDATE.S7S
