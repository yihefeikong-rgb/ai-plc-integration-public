西门子 PROFINET 网络配置与诊断手册

========================================
第一部分：PROFINET 基础
========================================

PROFINET 通信类型：
  NRT(Non Real-Time): TCP/IP，配置/诊断，100ms级
  RT(Real Time): 以太网帧优先级标记，1~10ms 周期
  IRT(Isochronous Real Time): 硬件级时间同步，<1ms，用于运动控制

设备角色：
  IO Controller: PLC（S7-1200/1500/300/400）
  IO Device: 从站设备（ET200/变频器/阀岛等）
  IO Supervisor: 编程器/HMI（诊断用）

========================================
第二部分：TIA Portal 配置步骤
========================================

1. 硬件配置：
   - 在设备视图中添加 IO Controller (PLC)
   - 添加 IO Device（从 GSD/GSDML 导入设备描述）
   - 网络视图中用线缆连接 Controller 与 Device

2. IP/名称分配：
   - 每个设备需唯一 IP 地址（同一子网）
   - 每个设备需唯一 PROFINET 设备名称
   - 名称通过 DCP 协议下发（Online → Assign device name）
   - 建议命名规则: 系统-位置-功能 (如 hvac-b1f2-ahu1)

3. IO 地址分配：
   - 模块/子模块的输入/输出地址自动或手动分配
   - 注意: 输入起始地址和输出起始地址独立
   - 避免地址冲突（TIA 会自动检查）

4. 实时通信设置：
   - 更新时间: 默认 8ms（可调 1/2/4/8/16/32/64/128ms）
   - 看门狗时间: 通常 3× 更新时间
   - 减小更新时间可提高响应但增加 CPU 负担

========================================
第三部分：网络拓扑
========================================

支持的拓扑：
  星型: 通过交换机集中连接（最常用）
  线型: 设备串联（内置交换机级联）
  环形: MRP(Media Redundancy Protocol)冗余
  树型: 星型+线型混合

MRP 介质冗余：
  - 一个 MRP 环最多 50 个设备
  - 切换时间 < 200ms（标准） / < 10ms（增强）
  - PLC 通常作为 MRP Manager
  - 其他设备作为 MRP Client

网络规划建议：
  - 控制网络与办公网络物理隔离
  - 使用工业级交换机（SCALANCE X 系列）
  - 线缆: 工业以太网电缆（Cat5e 以上，FastConnect）
  - 最大段长: 铜缆 100m，光纤取决于类型
  - 每个交换机端口不超过 5 级级联

========================================
第四部分：诊断与故障排查
========================================

PROFINET 诊断信息：
  通道诊断: 具体模块/通道的故障（短路、断线等）
  端口诊断: 链路状态、邻居信息
  设备诊断: 设备级故障代码

TIA Portal 诊断工具：
  在线视图: 设备状态（绿=OK/橙=维护/红=故障）
  拓扑视图: 实际连接 vs 组态对比
  报文追踪: 抓取 PROFINET 帧分析

常见故障及处理：
  "BF" LED 闪烁（设备上）:
    → 设备名称未分配或不匹配
    → IP 地址冲突
    → GSD 版本不匹配
    → 解决: Online → Assign device name

  通信中断/看门狗超时:
    → 线缆接触不良（检查RJ45接头）
    → 交换机端口故障
    → EMC干扰（检查屏蔽接地）
    → 解决: 更换线缆/端口，检查接地

  IO 数据不更新:
    → 检查更新时间设置
    → 检查模块是否被组态（灰色=未组态）
    → 解决: 重新编译下载硬件组态

========================================
第五部分：S7 通信（PLC 间）
========================================

PUT/GET 通信：
  - 无需组态连接
  - 需目标PLC开启"允许来自远程PUT/GET访问"
  - 适用于偶发数据交换
  - 安全性较低（任何人都可读写）

开放式通信（TSEND_C/TRCV_C）：
  - 建立 TCP/UDP 连接
  - 灵活数据长度
  - 可与非西门子设备通信

S7 通信（FB15 PUT / FB14 GET）：
  - 经典 S7 协议
  - 适用于 S7-300/400 间
  - S7-1500 建议用 PUT/GET 或 OPC UA
