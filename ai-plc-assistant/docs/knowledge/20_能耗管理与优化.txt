工业/楼宇能耗管理与优化手册

========================================
第一部分：能耗监测体系
========================================

电能监测：
  三相电参数: U(电压)/I(电流)/P(有功)/Q(无功)/S(视在)/PF(功率因数)/f(频率)
  电能累计: kWh(有功)/kvarh(无功)
  需量管理: 15min 滑动窗口最大需量 (kW)
  谐波分析: THD(总谐波畸变率)、1~31次谐波含量

  PLC采集方式:
    Modbus RTU/TCP: 读取智能电表寄存器
    脉冲计量: 高速计数器采集 kWh 脉冲(如 1000脉冲/kWh)
    直接接入: AI模块接电流互感器(0-5A → 4-20mA变送)

水/气/热量监测：
  水流量: 电磁流量计 / 超声波流量计 (4-20mA / Modbus)
  冷热量: Q = V × ρ × Cp × ΔT（配对温度+流量）
  天然气: 涡街/膜式流量计 + 温压补偿
  蒸汽: 涡街流量计 + 温度压力补偿 → 质量流量

========================================
第二部分：能效指标计算
========================================

制冷系统 COP 计算：
  COP = Q_cool / P_input
  Q_cool = V_chw × ρ × Cp × (T_return - T_supply)  [kW]
  P_input = 冷机 + 冷冻泵 + 冷却泵 + 冷却塔 [kW]

  目标: 系统 COP > 4.0 (优秀 > 5.0)

水泵效率：
  η_pump = Q × H × ρ × g / P_shaft
  变频效率: 功率与转速的三次方关系 P ∝ n³
  节能率计算: (1 - (n2/n1)³) × 100%

单位面积能耗 (EUI)：
  EUI = 年总能耗(kWh) / 建筑面积(m²)
  参考值:
    甲级写字楼: 80~120 kWh/m²/年
    商场: 150~250 kWh/m²/年
    医院: 200~300 kWh/m²/年

========================================
第三部分：PLC 侧节能策略
========================================

变频节能：
  - 泵/风机使用变频器代替阀门调节
  - 二次方V/f特性(风机/泵负载)
  - 休眠唤醒(低负荷停泵保压)
  - 节能公式: P_save = P_rated × (1-(Q2/Q1)³)

时间表优化：
  - 提前开机时间优化(根据热惯性计算)
  - 最优停机时间(利用建筑蓄热)
  - 周末/节假日自动切换模式
  - 加班延时模式(按需延长运行)

负荷预测：
  - 基于天气预报的冷/热负荷预测
  - 基于历史数据的负荷模式识别
  - 预冷/预热策略(利用电价低谷)

设备台数优化：
  - 冷机COP曲线：部分负荷效率更高(60-80%最优)
  - 多机组加减逻辑基于能效而非简单负荷
  - 避免低效率点运行(如<30%负荷)

========================================
第四部分：分时电价响应
========================================

三部电价结构(中国工商业)：
  尖峰(11:00-12:00, 19:00-21:00): 基准×1.7
  高峰(08:00-11:00, 13:00-19:00): 基准×1.5
  平段(07:00-08:00, 21:00-23:00): 基准×1.0
  低谷(23:00-07:00): 基准×0.4

PLC 电价响应策略：
  1. 蓄冷/蓄热: 低谷蓄能 → 尖峰释放
  2. 需量管理: 接近合同容量时切非重要负荷
  3. 柔性负荷: 高峰时降低空调设定(预冷补偿)
  4. 照明调度: 高峰时自然光区域优先降灯

========================================
第五部分：数据存储与报表
========================================

PLC 数据记录：
  DB 循环缓冲区: 15min/1h 采样存入数组
  S7-1500 DataLog: CSV文件记录到存储卡
  上传策略: OPC UA / S7 通信定期读取到上位系统

能耗报表内容：
  日报: 各系统日用电量、峰谷比、异常告警
  月报: 月度能耗对比、同比/环比、EUI
  年报: 年度趋势、节能量核算、碳排放折算

碳排放折算(中国电网)：
  CO2 = kWh × 0.5703 kgCO2/kWh (2023年全国平均)
