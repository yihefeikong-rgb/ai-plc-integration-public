西门子 S7 安全编程与 F-CPU 手册

========================================
第一部分：F-CPU 基础
========================================

什么是 F-CPU：
  故障安全 CPU，在标准自动化系统上集成安全功能。
  标准程序和安全程序在同一 CPU 中并行运行。
  需要 STEP 7 Safety Advanced 许可证。
  F-能力默认激活（安装 Safety 许可证时）。
  必须设置密码保护安全程序防止未授权访问。

何时需要：
  - 系统具有更高安全要求（人员/环境安全）
  - 需要立即关断时不危及人员或环境
  - 根据 IEC 62061 或 EN ISO 13849-1 要求的安全功能

========================================
第二部分：安全等级
========================================

SIL (IEC 62061) 与 PL (ISO 13849-1) 对照：
  SIL 1 / PL c — PFH 10^-6 到 10^-5，简单防护功能
  SIL 2 / PL d — PFH 10^-7 到 10^-6，安全门、光幕
  SIL 3 / PL e — PFH 10^-8 到 10^-7，急停、压力机安全

类别定义（EN ISO 13849-1）：
  Cat B — 基本，简单组件
  Cat 1 — 经过验证的组件，单通道
  Cat 2 — 带测试的单通道
  Cat 3 — 双通道，单故障可检测
  Cat 4 — 双通道，每个故障立即可检测

========================================
第三部分：F-I/O 模块
========================================

故障安全数字输入模块（F-DI）：
  检测安全相关传感器的信号状态。
  集成断线检测、差异监控、交叉故障检测。
  通过 PROFIsafe 发送安全帧到 F-CPU。

故障安全数字输出模块（F-DO）：
  控制安全相关执行器。
  冗余输出切断。

S7-1500 F-DI 示例（6ES7526-1BH00-0AB0）：
  16 个数字输入带安全功能。
  支持通道对配置。
  评估模式：1oo2 评估，等效。

========================================
第四部分：安全程序结构
========================================

F-Runtime Group（F-运行时组）：
  S7-1200/1500 F-CPU 的安全程序由 1-2 个 F-运行时组组成。
  每个 F-运行时组包含：
  - F-OB（定义安全程序调用结构）
  - 主安全块 F-FB 或 F-FC
  - F-DB（故障安全数据块）

默认创建：
  FOB_RTG1 [OB123]
  Main_Safety_RTG1 [FB1]

推荐使用"循环中断"事件类来保证固定时间间隔执行。

F-块类型：
  F-OB — 定义安全程序调用结构
  F-FB — 带实例 DB 的故障安全功能块
  F-FC — 故障安全函数
  F-DB — 故障安全数据块
  F-Shared DB — 安全程序的共享数据

安全程序编程语言：仅 LAD 和 FBD（不支持 SCL/STL）。

安全指令库包含：
  - 位逻辑、数学函数、程序控制、字逻辑
  - 安全特定指令：双手监控、差异分析、消隐（Muting）
  - 急停/紧急关断、安全门监控、反馈监控
  - F-CPU 间安全通信指令

========================================
第五部分：急停回路设计
========================================

设计要求（EN ISO 13850，达到 SIL 3 / PL e）：
  - 双通道设计，冗余 NC 触点
  - 差异监控和交叉电路监控
  - 两个接触器作为执行器（双通道切断）
  - F-CPU + ET 200SP F-I/O，通过 PROFIsafe 通信

TIA Portal 配置：
  - 通道对配置为"1oo2 评估，等效"
  - 设置每通道的暗测试和开关差异时间（10-50ms）
  - F-目的地址分配确保安全通信

认证功能块：ESTOP1
  - 已通过 EN ISO 13850 认证的急停功能块
  - 只需配置少量参数即可使用

========================================
第六部分：光幕集成
========================================

光幕类型与安全等级：
  Type 2 — PL c / SIL CL 1
  Type 3 — PL d / SIL CL 2
  Type 4 — PL e / SIL CL 3

消隐（Muting）：
  临时自动暂停光幕保护功能。
  允许物料通过光幕而不停止危险运动。
  使用多个传感器检测物料序列和时间。
  L 型双传感器消隐仅用于出口点。
  符合 IEC/TS 62046 技术规范。

========================================
第七部分：双手控制
========================================

  - 确保操作员双手远离危险区域
  - 要求两个按钮在规定时间窗口内（通常 0.5 秒）同时按下
  - 需要安全继电器或安全 PLC 评估
  - 符合 EN 574 / ISO 13851 标准

========================================
第八部分：安全验证工具
========================================

SISTEMA 软件：
  用于计算 PL（性能等级）。
  输入安全功能参数（MTBF、诊断覆盖率）。
  计算 PFH/PFD 值并验证目标 PL。

安全评估工具（SET）：
  验证架构是否达到目标 SIL。
  选择 F-CPU 作为逻辑求解器。
  配置双通道架构。
  运行 SIL 计算验证。

========================================
第九部分：安全编程注意事项
========================================

  - 安全程序仅支持 LAD 和 FBD 语言
  - 安全程序必须设置密码保护
  - 安全参数保持型（Retentive）
  - 安全通信通过 PROFIsafe 协议
  - F-CPU 支持标准程序和安全程序并行运行
  - 安全程序更新需重新验证安全功能
  - 禁用安全相关变量在 HMI 上的写入权限
  - 安全程序需使用经过认证的功能块
