西门子 S7-1200/S7-1500 LAD/FBD 指令集参考手册

========================================
第一部分：指令总体分类
========================================

S7-1200/S7-1500 的 LAD（梯形图）和 FBD（功能块图）指令按以下类别组织：
1. 位逻辑运算 — 触点、线圈、置位/复位、边沿检测
2. 定时器运算 — TP/TON/TOF/TONR
3. 计数器运算 — CTU/CTD/CTUD
4. 比较器运算 — CMP/IN_RANGE/OUT_RANGE
5. 数学函数 — ADD/SUB/MUL/DIV 及高级数学
6. 传送运算 — MOVE/MOVE_BLK/SWAP
7. 转换运算 — CONVERT/NORM_X/SCALE_X
8. 程序控制运算 — JMP/RET/CALL
9. 字逻辑运算 — AND/OR/XOR/取反
10. 移位和循环 — SHR/SHL/ROR/ROL

========================================
第二部分：位逻辑指令
========================================

常开触点 ---| |---
  当关联位=1 时闭合，允许"电流流过"。
  用于检测 I/Q/M/DB 位状态。

常闭触点 ---|/|---
  当关联位=0 时闭合，位为 1 时断开。

输出线圈 ---( )---
  有电流流过时输出位=1，无电流时=0。

取反线圈 ---(/)---
  有电流流过时输出位=0，无电流时=1。

置位线圈 ---(S)---
  将输出位设为 1 并保持（锁存），无论后续电流状态如何。

复位线圈 ---(R)---
  将输出位设为 0 并保持。

SR 触发器（复位优先）
  S 输入端置位，R1 输入端复位。
  若 S 和 R1 同时为 1，输出 Q=0（复位优先）。

RS 触发器（置位优先）
  S1 输入端置位，R 输入端复位。
  若 S1 和 R 同时为 1，输出 Q=1（置位优先）。

上升沿检测 ---(P)--- / ---|P|---
  检测 0→1 跳变，产生一个扫描周期的脉冲。
  需要一个辅助位（M_BIT）存储上一次的输入状态。

下降沿检测 ---(N)--- / ---|N|---
  检测 1→0 跳变，产生一个扫描周期的脉冲。
  需要一个辅助位（M_BIT）存储上一次的输入状态。

边沿检测注意事项：
  - M_BIT 仅使用 M、全局 DB 或静态存储器（实例 DB 中）
  - 每个边沿指令必须使用唯一的辅助位
  - 该辅助位不得在程序其他位置使用

即时读写（S7-1500 特有）
  - 输入即时读取：I0.1:P / IB4:P — 直接读物理输入，绕过过程映像
  - 输出即时写入：Q1.1:P / QB5:P — 直接写物理输出，不等待过程映像更新

========================================
第三部分：定时器指令（IEC 定时器）
========================================

每个定时器使用 16 字节的 IEC_Timer 数据类型 DB 结构。
STEP 7 在插入指令时自动创建 DB。

TP — 脉冲定时器（Pulse Timer）
  功能：IN 上升沿触发后，Q=1 持续 PT 时间。
  特点：运行期间 IN 变化无效，固定脉冲宽度。
  应用：指示灯闪烁、按钮去抖、驱动启动脉冲。

TON — 接通延时（On-Delay）
  功能：IN=1 后延时 PT 时间，Q 才变为 1。
  特点：IN 在计时中变 0 则复位。
  应用：信号滤波、软启动、忽略短脉冲干扰。

TOF — 断开延时（Off-Delay）
  功能：IN 从 1 变 0 后，Q 保持 1，延时 PT 后 Q 才变 0。
  特点：IN 在计时中变 1 则复位。
  应用：风扇延时关闭、灯光延时灭。

TONR — 保持型接通延时（Retentive On-Delay）
  功能：类似 TON，但 IN=0 时暂停计时（不复位）。
  特点：累计多次计时直到达到 PT，需用 R 输入复位。
  应用：运行时间累计、报警持续时间记录。

定时器参数：
  IN (BOOL) — TP/TON/TONR：1=启动，0=停止；TOF：0=启动，1=停止
  R (BOOL) — 仅 TONR：1=复位已用时间和 Q 位
  PT (TIME) — 预设时间，格式 T#200ms, T#5s, T#2s_200ms
  Q (BOOL) — 定时器状态输出
  ET (TIME) — 已用时间输出

TIME 数据类型：32 位，以 DInt 存储（毫秒）
  范围：T#-24d_20h_31m_23s_648ms 到 T#24d_20h_31m_23s_647ms

========================================
第四部分：计数器指令（IEC 计数器）
========================================

CTU — 递增计数（Count Up）
  CU 上升沿时 CV+1。当 CV>=PV 时 Q=1。
  R=1 时 CV 复位为 0。
  应用：产品计数、批次计数。

CTD — 递减计数（Count Down）
  CD 上升沿时 CV-1。当 CV<=0 时 Q=1。
  LD=1 时将 PV 加载到 CV。
  应用：剩余数量显示、倒计数。

CTUD — 递增/递减计数（Count Up/Down）
  CU 上升沿 CV+1，CD 上升沿 CV-1。
  QU=1 当 CV>=PV，QD=1 当 CV<=0。
  同一周期 CU 和 CD 同时有上升沿时 CV 不变。
  应用：位置跟踪、库存管理。

计数器参数：
  CU (BOOL) — 递增计数（上升沿触发）
  CD (BOOL) — 递减计数（上升沿触发）
  R (BOOL) — 复位（CTU/CTUD），优先级最高
  LD (BOOL) — 加载预设值（CTD/CTUD）
  PV (SInt/Int/DInt/USInt/UInt/UDInt) — 预设值
  Q (BOOL) — CTU: CV>=PV 时为 1；CTD: CV<=0 时为 1
  CV (对应整数类型) — 当前计数值

注意事项：
  - 计数器仅检测上升沿，持续高电平不会重复计数
  - 最大计数速率受 OB 执行速率限制，高速计数使用 CTRL_HSC
  - Int 范围 -32768~32767，长期运行建议使用 DInt/UDInt

========================================
第五部分：比较器指令
========================================

比较器在 LAD 中作为触点使用，在 FBD 中作为功能块使用。

CMP ==    等于       IN1 = IN2 时 RLO=1
CMP <>    不等于     IN1 != IN2 时 RLO=1
CMP >     大于       IN1 > IN2 时 RLO=1
CMP <     小于       IN1 < IN2 时 RLO=1
CMP >=    大于等于   IN1 >= IN2 时 RLO=1
CMP <=    小于等于   IN1 <= IN2 时 RLO=1
IN_RANGE  范围内     MIN <= VAL <= MAX 时输出 1
OUT_RANGE 范围外     VAL < MIN 或 VAL > MAX 时输出 1

支持的数据类型：位串、整数、浮点数、字符串、定时器值、日期时间。

注意事项：
  - 比较 REAL/LREAL 时，建议使用 IN_RANGE 代替 CMP ==
  - 两个操作数必须是相同数据类型（启用 IEC 检查时）

========================================
第六部分：数学函数指令
========================================

基本算术：
  ADD — 加法，可扩展多输入
  SUB — 减法 IN1 - IN2
  MUL — 乘法，可扩展多输入
  DIV — 除法 IN1 / IN2（整数除法截断小数）
  MOD — 取余 IN1 MOD IN2
  NEG — 取反 -IN，生成二进制补码
  ABS — 绝对值 ABS(IN)
  INC — 递增 IN + 1
  DEC — 递减 IN - 1

高级数学：
  MIN — 取最小值
  MAX — 取最大值
  LIMIT — 限幅（设定上下限）
  SQR — 平方
  SQRT — 平方根
  LN — 自然对数
  EXP — 指数 e^x
  SIN / COS / TAN — 三角函数

支持的数据类型：SInt, Int, DInt, USInt, UInt, UDInt, Real, LReal
所有参数（IN1, IN2, OUT）必须是相同数据类型。

ENO 错误状态：
  ENO=0 表示：结果溢出、除以零、输入为 NaN、INF 运算异常

========================================
第七部分：传送与转换指令
========================================

MOVE — 将 IN 的内容复制到 OUT1
  无数据类型转换，源和目标必须类型一致。
  可扩展多个输出。

MOVE_BLK — 移动块，复制 ARRAY 数据类型的操作数
UMOVE_BLK — 不可中断的移动块
MOVE_BLK_VARIANT — 复制数组（S7-1500 和 S7-1200 FW4.1+）
SWAP — 字节交换

CONVERT — 通用转换，在数值格式和数据类型之间转换
NORM_X — 标准化：将输入值映射为 0.0~1.0 的浮点数
SCALE_X — 缩放：将标准化值映射到工程单位
ROUND — 四舍五入
CEIL — 向上取整
FLOOR — 向下取整
TRUNC — 截断（向零取整）

MOVE 注意事项：
  - 若 IN 位长度 > OUT 位长度，高位丢失
  - 若 IN 位长度 < OUT 位长度，目标高位填零

========================================
第八部分：程序控制指令
========================================

JMP — 条件跳转，跳转到同一块内的标签
JMPN — 条件不跳转，RLO=0 时跳转
LABEL — 跳转目标标签
RET — 退出当前块返回调用者
CALL — 调用代码块

编程建议：
  - 避免使用 JMP/Label 结构，优先使用结构化编程
  - S7-1200 不支持 STL（语句表）

========================================
第九部分：字逻辑与移位指令
========================================

字逻辑：
  WAND_W / WAND_DW — 字/双字按位与
  WOR_W / WOR_DW — 字/双字按位或
  WXOR_W / WXOR_DW — 字/双字按位异或
  INV — 按位取反

移位与循环：
  SHR — 右移
  SHL — 左移
  ROR — 循环右移
  ROL — 循环左移

========================================
第十部分：寻址方式与数据类型
========================================

存储区标识：
  I — 过程映像输入（每个扫描周期前采样物理输入）
  Q — 过程映像输出（复制值到物理输出）
  M — 位存储器/中间变量
  DB — 数据块（全局或实例数据块）
  L — 临时存储器（仅限当前块，符号寻址）
  T — 定时器（仅 S7-1500）
  C — 计数器（仅 S7-1500）

绝对寻址格式：
  I0.1 / Q2.3 / M203.7 — 位寻址 [字节].[位]
  IB0 / QB5 / MB20 — 字节寻址 Area+B+起始字节
  IW4 / QW10 / MW30 — 字寻址 Area+W+起始字节（2 字节）
  ID8 / QD40 / MD50 — 双字寻址 Area+D+起始字节（4 字节）
  DBX4.2 / DBB0 / DBW0 / DBD0 — 数据块内寻址

常用数据类型：
  BOOL — 1 位，值 0/1
  BYTE — 8 位，0~255
  WORD — 16 位，0~65535
  DWORD — 32 位，0~4294967295
  SInt — 8 位，-128~127
  Int — 16 位，-32768~32767
  DInt — 32 位，-2147483648~2147483647
  Real — 32 位浮点，+-3.4e38
  LReal — 64 位浮点，+-1.7e308
  Time — 32 位，T#-24d~T#24d（毫秒）

关键注意事项：
  - 优化数据块（S7-1200/1500 默认）不支持绝对寻址
  - 内存重叠：MD8 占用字节 8-11，MW8 占用 8-9，写入 MD8 覆盖 MW8/MB8
  - WORD 使用偶数字节地址，DWORD 使用 4 字节对齐地址
  - S7-1500 建议避免使用 M 存储器，优先使用数据块

========================================
第十一部分：LAD 与 FBD 区别
========================================

LAD（梯形图）：类似电气继电器电路
  - 基本元素：触点、线圈、横向支路
  - OR 逻辑用并联支路
  - 流行区域：北美
  - 每个网络必须以线圈或功能块结尾

FBD（功能块图）：类似逻辑门/布尔代数
  - 基本元素：功能块、连接线
  - OR 逻辑用 OR 功能块
  - 流行区域：欧洲
  - 无网络结尾限制

编译结果：相同的机器代码
