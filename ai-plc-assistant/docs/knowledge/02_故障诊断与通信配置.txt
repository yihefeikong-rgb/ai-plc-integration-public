西门子 S7-1200 故障诊断与通信配置技术手册

========================================
第一部分：CPU LED 状态指示灯
========================================

STOP/RUN 指示灯：
- 黄色常亮：CPU 处于 STOP 模式
- 纯绿色常亮：CPU 处于 RUN 模式
- 绿色/黄色交替闪烁：CPU 处于 STARTUP 启动模式

ERROR 指示灯：
- 红色闪烁：出错（CPU 内部错误、存储卡错误或组态错误）
- 红色闪烁3秒：临时错误（如实时时钟在断电时重置）
- 红色常亮：硬件故障（最严重）
- 所有 LED 闪烁：固件检测到致命故障

MAINT 维护指示灯：
- 橙色闪烁：每次插入存储卡时闪烁
- 橙色常亮：有维护请求或变量处于强制状态

PROFINET 通信指示灯：
- Link 绿色点亮：以太网连接成功
- Rx/Tx 黄色点亮：正在数据传输

========================================
第二部分：诊断缓冲区常见事件
========================================

诊断缓冲区最多支持 50 个条目（FIFO，最新在前）。

常见事件：
- 硬件组件已移除或缺失 → 组态了不存在的模块
- I/O 访问错误 → 启动时模块缺失
- 未装载 DBx → 程序引用了未下载的数据块
- 超出上限/下限 → 模拟量信号超出报警阈值
- 区域长度错误 → 数据访问越界
- 断路（Wire break）→ 模拟量传感器线路断裂
- 短路 → 输出通道或传感器线路短路
- 模块故障 → 硬件损坏或供电异常
- 通信超时 → PROFINET/Modbus 通信超时

诊断 OB 事件：
- OB80：时间错误（周期超时）
- OB82：诊断中断（模块诊断状态变化）
- OB83：模块插拔事件
- OB86：机架错误

========================================
第三部分：S7 通信错误代码表
========================================

PUT/GET 通信错误代码：
- 0x0000：无错误，执行成功
- 0x7001：连接未建立 → 检查 IP 地址、TSAP、网络连接
- 0x8104：目标地址无效 → 确认服务器端数据块存在且未被锁定
- 0x80F1：访问被拒绝 → 在两台 CPU 中启用 PUT/GET 通信权限
- 0x809A：伙伴设备不可达 → 检查 IP、子网掩码、网线
- 0x80C3：连接资源耗尽 → 减少并发连接数或重启 CPU
- 0x80B4：地址参数错误 → 检查指针语法 P#DBx.DBXy.z
- 0x8301：访问权限不足 → 服务器端启用 PUT/GET 远程访问
- 0x8500：数据类型不匹配 → 检查 ADDR 和 RD/SD 格式一致性
- 0x1E80：不允许优化访问 → 取消数据块的"优化块访问"勾选

========================================
第四部分：PROFINET 通信配置
========================================

基本 IO 设备组态步骤：

Step 1：创建项目并配置接口参数
- 在 TIA Portal 网络视图添加所有设备
- 为每台设备设置 IP 地址和子网掩码
- 设置 PROFINET 设备名称（区分大小写，必须完全一致）

Step 2：IO 设备硬件组态
- 双击 IO 设备进入设备视图
- 添加 IO 模块（DI、DQ、AI、AQ）

Step 3：分配 IO 设备给控制器
- 在网络视图左键点击 IO 设备的"未分配"图标
- 选择对应的 IO 控制器

Step 4：分配设备名称
- 右键 PROFINET 网络 → 分配 PROFINET 设备名称
- 通过 MAC 地址确认目标设备
- 等待状态变为"确定"

Step 5：编译下载测试

GSD 文件导入步骤：
1. TIA Portal：选项 → 管理通用站描述文件 (GSD)
2. 选择 GSD 文件源路径
3. 选择需要安装的文件并点击"安装"
4. 设备出现在硬件目录的"其它现场设备"中

========================================
第五部分：Modbus RTU 通信配置
========================================

MB_COMM_LOAD 功能块参数（在 OB100 启动 OB 中调用）：
- REQ：上升沿触发，OB100 中可直接设为 TRUE
- PORT：通信模块硬件标识符
- BAUD：波特率（9600/19200/38400/115200 等）
- PARITY：0=无校验，1=奇校验，2=偶校验
- RESP_TO：响应超时（ms），默认 1000
- MB_DB：必须指向 MB_MASTER 或 MB_SLAVE 的背景数据块

MB_MASTER 主站指令参数：
- REQ：上升沿触发，由上一次 DONE=1 触发下一次
- MB_ADDR：从站地址（1~247）
- MODE：0=读取，1=写入
- DATA_ADDR：Modbus 数据起始地址
- DATA_LEN：数据长度
- DATA_PTR：数据缓冲区指针（如 P#DB3.DBX0.0 WORD 5）

Modbus 功能码映射：
- FC01（MODE=0, ADDR 00001~09999）：读线圈（Q 区）
- FC02（MODE=0, ADDR 10001~19999）：读离散输入（I 区）
- FC03（MODE=0, ADDR 40001~49999）：读保持寄存器
- FC04（MODE=0, ADDR 30001~39999）：读输入寄存器
- FC05/FC15（MODE=1, ADDR 00001~09999）：写线圈
- FC06/FC16（MODE=1, ADDR 40001~49999）：写保持寄存器

重要注意：DATA_PTR 指向的 DB 块必须使用标准访问（非优化访问）

Modbus RTU 配置步骤：
1. 硬件组态：插入 CM1241 通信模块（RS485 或 RS232）
2. 通信参数设置：波特率、停止位、校验需与从站一致
3. 在 OB100 中调用 MB_COMM_LOAD
4. MB_DB 引脚连接到 MB_MASTER/MB_SLAVE 的背景数据块
5. 在 OB1 中调用 MB_MASTER 或 MB_SLAVE
6. 创建数据缓冲区 DB 块（标准访问类型）

Modbus TCP 配置：
- 使用 MB_SERVER 指令
- IP_PORT：标准端口 502
- 不需要 MB_COMM_LOAD（TCP 使用以太网口）

========================================
第六部分：PUT/GET 通信配置
========================================

启用 PUT/GET 步骤（TIA Portal V13~V18）：
1. 双击"设备配置"打开硬件配置
2. 点击 CPU 模块选中
3. 导航至：属性 → 常规 → 保护（Protection & Security）
4. 访问级别设为"完全访问（无保护）"
5. 单独勾选："允许通过 PUT/GET 通信进行访问"
6. 保存、编译、下载到 CPU

注意：
- PUT/GET 权限是独立的复选框，不随"完全访问"自动启用
- 新项目中默认未启用
- 两台 PLC 都需要启用
- 修改后必须重新下载到 CPU

GET 指令（FB14）从远程 PLC 读取数据：
- REQ：上升沿触发读取请求
- ID：S7 连接标识号（如 W#16#0001）
- ADDR_1：远程存储区地址（如 P#DB1.DBX0.0 BYTE 10）
- RD_1：本地接收区
- NDR：=1 表示读取成功

PUT 指令（FB15）向远程 PLC 写入数据：
- REQ：上升沿触发写入请求
- ID：S7 连接标识号
- ADDR_1：远程存储区地址
- SD_1：本地发送区
- DONE：=1 表示写入完成

寻址格式：
- P#DB1.DBX0.0 BYTE 10：DB1 从偏移 0.0 开始的 10 字节
- P#DB2.DBX0.0 WORD 5：DB2 从偏移 0.0 开始的 5 个字
- P#M100.0 WORD 10：M 区从 100.0 开始的 10 个字

数据块要求：
- 服务器端 DB 必须使用"非优化访问"
- S7-1200 单次 PUT/GET 最大数据量：222 字节
- S7-1200 最大并发 S7 连接数：8 个

S7 通信连接建立步骤：
1. 进入 TIA Portal 网络视图
2. 连接类型选择"S7 连接"
3. 右键 CPU → 添加新连接
4. 选择目标 PLC
5. 配置连接 ID（需与 PUT/GET 指令的 ID 一致）
6. 勾选"主动建立连接"（客户端侧）
7. 编译并下载
