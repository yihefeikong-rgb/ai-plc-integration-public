西门子 S7 PID 控制与模拟量处理手册

========================================
第一部分：PID 控制器类型
========================================

PID_Compact — 通用 PID 控制器
  用于连续控制和脉冲宽度调制。
  比例行为执行器，适用温度、压力、流量等通用控制。
  内置 PIDT1 控制器结构，含抗积分饱和和比例/微分加权。

PID_3Step — 积分行为执行器 PID
  用于三位置步进控制器，带或不带位置反馈。
  适用于阀门等积分行为执行器。

PID_Temp — 温度专用 PID
  用于加热/冷却应用，支持两个输出。
  内置 PIDT1 控制器结构。

========================================
第二部分：PID 自整定
========================================

自动整定分两步：

预整定（Pretuning）：
  - 确定过程对输出值阶跃变化的响应
  - 搜索拐点，从最大上升率和死区时间计算 PID 参数
  - 要求：设定值与过程值之差 > 30% 过程值范围
  - 完成后自动切换到自动模式

精细整定（Fine Tuning）：
  - 产生恒定有限的过程值振荡
  - 根据振荡的幅值和频率重新计算 PID 参数
  - 通常比预整定产生更好的控制特性
  - 建议在自动模式下启动以改进现有参数

========================================
第三部分：PID 工作模式
========================================

状态值说明：
  State=0 — 非活动，控制器不活动
  State=1 — 预整定，正在执行预整定
  State=2 — 精细整定，正在执行精细整定
  State=3 — 自动，PID 按配置参数修正系统
  State=4 — 手动，使用 ManualValue 作为输出值

切换模式：修改 Mode 参数并在 ModeActivate 上给出上升沿。
手动模式：使用 ManualValue 作为输出值。

PID 调用要求：
  - 必须在循环中断 OB 的恒定时间刻度中调用
  - 采样时间理想地等于调用 OB 的周期时间
  - 若在 OB1 中调用需禁用采样时间监控（控制质量降低）
  - PID 参数全部保持型（Retentive）

========================================
第四部分：PID 参数参考范围
========================================

温度控制：
  Kp（增益）: 1-20
  Ti（积分时间 分钟）: 2-20
  Td（微分时间 分钟）: 0.2-5
  唯一推荐使用微分的变量，测量滞后大。

流量控制：
  Kp: 0.3-1.5
  Ti: 0.1-0.5
  Td: 0（禁用微分）
  快速响应，PI 控制即可，微分会放大噪声。
  建议添加 0.5-2 秒一阶滤波。

压力控制：
  Kp: 0.5-5
  Ti: 0.5-5
  Td: 0-0.2
  保守增益，压力可能产生危险尖峰。

液位控制：
  Kp: 1-10
  Ti: 1-10
  Td: 0（禁用微分）
  积分过程，常用 P 或松散 PI 控制。

成分/分析：
  Kp: 0.5-5
  Ti: 5-60
  Td: 1-10
  最慢过程，响应迟缓。

整定方法选择：
  Ziegler-Nichols — 激进，快速响应，约 25% 超调
  Cohen-Coon — 大死区时间下更好，适用 θ/τ > 0.3
  IMC/Lambda — 平滑保守无超调，温度环路理想选择
  Tyreus-Luyben — 最小超调，鲁棒稳定

关键经验：
  - 流量环路：PI 即可，禁用微分
  - 液位环路：绝不使用微分
  - 温度环路：微分有助于补偿热电偶测量滞后
  - 在实际运行温度下整定（150度整定的参数在250度会振荡）

========================================
第五部分：模拟信号处理
========================================

NORM_X（标准化）：
  将原始值映射到 0.0~1.0 的浮点值。
  公式：OUT = (VALUE - MIN) / (MAX - MIN)
  结果被限制在 0.0 <= OUT <= 1.0。

SCALE_X（缩放）：
  将标准化值映射回工程单位。
  公式：OUT = VALUE * (MAX - MIN) + MIN。

典型使用链：
  原始整数值 → NORM_X → 0.0~1.0 → SCALE_X → 工程单位

信号类型与原始值范围：
  0-10V / 0-20mA — 范围代码 2，原始值 0~27648
  4-20mA — 范围代码 4，原始值 5530~27648
  +-10V — 范围代码 3，原始值 -27648~+27648
  +-5V — 范围代码 1，原始值 -27648~+27648

关键值：27648 = 100% 满量程（所有 Siemens 模拟输入）

SCL 示例：4-20mA 缩放到工程值
  // NORM_X: 原始值标准化
  NORM_X(IN := %IW64,      // 模拟输入地址
         MIN := 5530,       // 4mA 对应值
         MAX := 27648,      // 20mA 对应值
         OUT := #raw_real);

  // SCALE_X: 标准化值缩放到工程单位
  SCALE_X(IN := #raw_real,
          MIN := 0.0,       // 工程最小值
          MAX := 188.0,     // 工程最大值
          OUT := #pressure_psi);

========================================
第六部分：模拟输入模块配置
========================================

SM 1231 模拟输入配置参数：
  测量类型 — 电压/电流，匹配传感器输出
  测量范围 — 工业变送器用 4-20mA
  电阻 — 4-20mA 二线制变送器设置 250Ω
  输出范围（AO）— 匹配执行器要求

========================================
第七部分：热电偶与热电阻（RTD）
========================================

RTD 模块配置（TIA Portal）：
  1. 选择传感器类型（Pt100/Pt1000/Ni100 等）
  2. 设置连接类型（2线/3线/4线），4线精度最高
  3. 设置温度单位（°C/°F/K）
  4. 设置测量范围（Pt100: -200°C ~ +850°C）

RTD 输出格式：
  温度值以所选单位的十分之一表示。
  示例：235 = 23.5°C（标准模式，1 digit = 0.1°C）
  气候模式：1 digit = 0.01°C（更高分辨率）

支持的热电偶类型：B, E, J, K, N, R, S, T

冷端补偿方式：
  内部温度补偿（模块内置传感器）
  外部 RTD 补偿（外接 Pt1000）
  固定 0°C 参考点补偿

诊断值：
  0x7FFF (32767) — 溢出/断线
  0x8000 (-32768) — 下溢/短路

常见故障排除：
  读数固定在 32767 — 开路/断线，检查接线
  读数固定在 -32768 — 短路，检查电缆损坏
  读数跳动 — 2线配置为4线模式，配置匹配实际接线
  偏移误差(+5°C) — 导线电阻未补偿，用3线或4线连接
  值固定在0或32767 — 模块未启用，在硬件配置中启用
