西门子 S7 变频器通信与控制手册

========================================
第一部分：变频器通信方式
========================================

USS 协议（通过 RS485）
  - 使用 USS_PORT_SCAN / USS_DRV 指令
  - 最多 31 个从站
  - 波特率 9600~115200
  - 适用于 SINAMICS G110/G120/V20 小功率驱动

PROFINET 通信（推荐）
  - 报文类型：标准报文1(PZD2/2)、报文20(PZD2/6)、报文352(含PI)
  - 控制字/状态字格式符合 PROFIdrive
  - 实时通信，支持等时同步模式
  - 适用于 SINAMICS G120/S120/S210

PROFIBUS DP
  - PPO 报文类型 1~5
  - 周期性通信 + 非周期参数访问
  - 适用于 MicroMaster 4xx / G120（DP接口）

Modbus RTU
  - V20 / G120 可选 Modbus RTU 通信模块
  - 功能码 03(读)/06(写单寄存器)/16(写多寄存器)
  - 寄存器映射参见变频器手册

========================================
第二部分：PROFIdrive 控制字/状态字
========================================

控制字 STW1 (Control Word 1)：
  Bit 0: ON/OFF1（通电/自由停车）
  Bit 1: OFF2（自由停车/抱闸）
  Bit 2: OFF3（快速停车）
  Bit 3: 使能运行
  Bit 4: 使能斜坡发生器
  Bit 5: 使能斜坡发生器+当前设定值
  Bit 6: 使能设定值
  Bit 7: 故障确认（上升沿）
  Bit 10: 由PLC控制
  Bit 11: 反转（0=正转 1=反转）

标准启动序列：
  Step 1: STW1 = 16#047E  （准备就绪）
  Step 2: STW1 = 16#047F  （启动运行）
  速度设定: NSOLL = 速度 × 16384 / 额定转速

状态字 ZSW1 (Status Word 1)：
  Bit 0: 准备接通
  Bit 1: 准备运行
  Bit 2: 运行使能
  Bit 3: 故障激活
  Bit 6: 接通禁止激活
  Bit 7: 报警激活
  Bit 8: 设定值/实际值偏差在公差范围内
  Bit 9: 请求控制
  Bit 10: 到达目标频率/速度

========================================
第三部分：G120 PROFINET 配置步骤
========================================

1. TIA Portal 中添加 G120 GSD 文件
2. 在网络视图中添加 G120 设备
3. 分配 PROFINET 名称和 IP
4. 选择通信报文类型（推荐标准报文1）
5. 在 PLC 程序中映射 PZD 数据区
6. 编写启动/停止/调速 FB

SCL 驱动控制框架示例结构：
  VAR_INPUT:
    bStart, bStop, bReset, bReversal : Bool
    rSpeedSetpoint : Real  // 0.0~100.0 %
  VAR_OUTPUT:
    bRunning, bFault, bReady : Bool
    rSpeedActual : Real
    rCurrent : Real

========================================
第四部分：故障处理
========================================

常见变频器故障码（SINAMICS）：
  F0001: 过流
  F0002: 过压
  F0003: 欠压
  F0004: 过温
  F0005: I2t 过载
  F0011: 电机过温
  F0015: 缺相
  F0021: 参数错误
  F0052: 功率单元故障
  F0070: PROFIBUS/PROFINET 通信中断

故障处理逻辑：
  1. 读取状态字 ZSW1.Bit3
  2. 如果故障：读取 F 故障代码
  3. 显示故障描述
  4. 操作员确认后发送故障确认（STW1.Bit7 上升沿）

========================================
第五部分：节能运行
========================================

能量优化模式：
  - V/f 控制（默认）：简单，适用于风机/泵
  - 矢量控制（SLVC）：精确速度控制
  - 伺服控制：高动态响应

节能策略：
  1. 启用自动节能模式（P1210=1 启用）
  2. 低负荷时自动降低磁通
  3. 泵/风机：启用二次方 V/f 特性（P1300=3）
  4. 休眠唤醒功能（低流量时变频器休眠）
